# IT International Academy & ITA TV

A comprehensive digital learning environment and automated broadcasting/streaming web platform designed to deliver technical education and media content.

🌐 **Live Demo:** [View ITA TV](https://ita-international-tv.pages.dev)

---

## Overview
IT International Academy (ITA) is an advanced educational ecosystem featuring integrated streaming capabilities (ITA TV) to support online learning, video instruction, and digital skills development.

## Features
* **Digital Learning Environment:** Structured course modules, student portals, and resource management.
* **ITA TV Broadcasting:** Integrated video streaming architecture for educational broadcasts and tutorials.
* **User Authentication & Management:** Secure login and role-based access for students and administrators.
* **Responsive UI:** Clean, modern interface optimized for desktop and mobile devices.

## Technologies Used
* **Frontend:** HTML, CSS, JavaScript, React
* **Backend & Cloud Services:** Supabase, Firebase
* **Deployment & Hosting:** Cloudflare Pages, Netlify, Vercel
* **Media & AI Tools:** Canva, video streaming integrations

## Project Purpose
Built as a practical digital learning and broadcasting platform to expand access to technology education and interactive learning resources.
